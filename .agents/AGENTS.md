# Workspace Agent Rules

## Pre-Building Consultation & User Interaction Style (Victor's Preferences)

1. **Always Ask Questions Before Building**:
   - Never proceed to build, generate full project structures, or make major architectural implementations without first consulting Victor.
   - Present initial concepts, key questions, choices, or architectural options and ask for Victor's input first.

2. **Attune to Thinking & Communication Style**:
   - Pay close attention to how Victor thinks, communicates, and envisions high-end projects.
   - Adapt responses to be collaborative, sharp, responsive, and aligned with high-end project standards.

---

## Mandatory Pre & Post Fix/Deployment Verification

1. **Pre-Fix / Pre-Deployment Inspection**:
   - Always inspect the exact target files, script definitions, and environment configurations before applying any code edit, bug fix, or deployment.
   - Never assume pre-existing code structure or variable schemas without direct file/code inspection.

2. **Post-Fix / Post-Deployment Verification**:
   - Immediately after applying any code change, bug fix, or script modification, run the appropriate test or execution command to verify that the fix works as expected.
   - Inspect the post-execution logs/state to confirm that no regressions or unexpected side-effects were introduced.
